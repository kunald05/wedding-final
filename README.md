# Saumya & Kunal — Wedding Microsite (GitHub Pages Flat Upload)

This package is intentionally structured for a GitHub repository where you upload **all files directly into the repository root**. No `assets` folder is required.

## Upload structure

Keep these files together at the repository root:

- `index.html`
- `styles.css`
- `script.js`
- `robots.txt`
- `page-1.jpg` through `page-7.jpg`
- `Amaran Violin.m4a`

## Important

If replacing the current website, delete the old website files first (or replace them), then upload **all files in this folder** to the repository root.

The invitation lightbox is explicitly hidden with CSS until opened, and all image/audio paths are root-relative for this flat GitHub Pages setup.
